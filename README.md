# Motion Editor Skills

Два связанных AI-скилла для редактируемого моушн-дизайна: отдельные анимации и графические вставки поверх разговорного видео. Инструкции на русском, сцены создаются в React/Remotion.

- **[motion-editor](skills/motion-editor/SKILL.md)** — режиссура по речи, выбор стиля, сцены, сборка и проверки.
- **[motion-style-creator](skills/motion-style-creator/SKILL.md)** — новые переиспользуемые стили по видеореференсам, картинкам или описанию; код, пробные рендеры и подключение к редактору.

В комплекте три независимых подстиля: `clean-editorial`, `paper-collage`, `retro-vhs`. Общая логика не смешивает их эстетику. Новый стиль добавляется своей папкой и записью в реестре; общий редактор переписывать не требуется.

## Как передать и начать

Можно просто передать ассистенту эту ссылку:

```text
https://github.com/rusanovproject-dotcom/motion-editor-skills

Установи ОБА скилла из папки skills рядом друг с другом. Сохрани все вложенные файлы,
три стилевых модуля и реестр. Затем прочитай их SKILL.md и помоги настроить локальный
Remotion engine по README. Существующие одноимённые skills не перезаписывай без проверки.
```

Либо клонируйте репозиторий и откройте его в своём кодовом ассистенте:

```sh
git clone https://github.com/rusanovproject-dotcom/motion-editor-skills.git
cd motion-editor-skills
```

Скиллы также можно скопировать в поддерживаемый вашим ассистентом каталог skills. Важна структура **две соседние папки**, а не отдельные SKILL.md:

```text
<skills-directory>/
├── motion-editor/          # копируется целиком
│   ├── SKILL.md
│   ├── scripts/
│   ├── assets/
│   ├── references/
│   └── styles/registry.json + три папки стилей
└── motion-style-creator/   # копируется целиком
    ├── SKILL.md
    ├── scripts/
    └── references/
```

В этом репозитории роль `<skills-directory>` выполняет `skills/`. Конструктор находит родителя по соседнему каталогу либо явно переданному пути. Автозагрузка зависит от хоста; без неё попросите ассистента явно прочитать нужный SKILL.md.

## Локальный движок

Для исполнения нужны Python 3.10+, Node.js 22, FFmpeg/ffprobe и Chromium для Remotion. Helper регистрации использует `fcntl`: macOS/Linux; на Windows используйте WSL. Сам ассистент/подписка/распознавание речи в комплект не входят. Зависимости не встроены и не скачиваются при scaffold.

Минимальный engine с зафиксированными версиями:

```sh
cd engine
npm install
npx remotion browser ensure
cd ..
```

Это отдельный шаг настройки с загрузкой пакетов/браузера. Если совместимый engine уже установлен, используйте его каталог в `--engine-root`, ничего повторно устанавливать не нужно. Для локального Chromium вне кеша движка передайте `--browser-executable /path/to/chromium` при scaffold. Проект связывается с node_modules engine: при переносе на другую машину создайте проект заново или восстановите это соединение; абсолютный путь исходной машины переносить нельзя.

Проверка реестра и пробный MP4:

```sh
python3 skills/motion-editor/scripts/style_registry.py --validate
python3 skills/motion-editor/scripts/scaffold_scene.py \
  --project outputs/demo --engine-root engine \
  --style clean-editorial --width 540 --height 960 --fps 30 --duration 6
sh outputs/demo/render.sh
```

Сначала это синтетическая стартовая сцена. Ассистент должен адаптировать предметы/движения под ваш текст и референс; генерация проекта сама по себе не означает точную копию примера.

## Примеры задач

**Отдельная анимация:**

> Используй motion-editor. Сделай отдельную анимацию в paper-collage: задача проходит от человека к агенту и возвращается на проверку. Нужны MP4 и редактируемый проект.

**Вставки поверх речи:**

> Используй motion-editor. Вот исходник и референс. Сделай предметные вставки на ключевых фразах. Лицо и субтитры должны оставаться открытыми. Сохрани речь и отдай готовый ролик с проектом.

**Новый стиль:**

> Используй motion-style-creator. По этим рефам придумай отдельный стиль для объяснялок, проверь на двух разных темах в полном кадре и поверх видео, затем подключи к motion-editor.

Для разговорного монтажа нужен ваш исходник. Без него можно создать стиль/прототип, но нельзя подтвердить синхронизацию речи и сохранность реального лица. `fullscreen` и `lower-panel` поддерживаются стартовым kit; свободные вырезки, side/split-композиции создаются в выходном проекте. H.264 MP4 не сохраняет прозрачность; отдельный alpha-слой экспортируется совместимым форматом.

## Добавление стилей и проверки

[Контракт расширения](skills/motion-editor/references/style-extension.md) описывает API модуля. [Приёмка конструктора](skills/motion-style-creator/references/integration.md) описывает staging, проверку двух тем в каждом заявленном layout и безопасную регистрацию. Registry helper не перезаписывает существующие стили; его QA receipt фиксирует просмотр, но не является автоматической оценкой красоты.

```sh
python3 -m unittest discover -s tests -v
```

Восемь регрессионных проверок используют стандартную библиотеку Python и FFmpeg, сеть не нужна. Короткий реальный рендер дополнительно требует установленного engine/browser. Для этой публикации проверены реестр, совместимость и короткие рендеры из переносимой копии; визуальное качество конкретного будущего ролика требует собственного просмотра.

В репозитории нет исходных референс-видео, личных записей, транскриптов, секретов, node_modules или внутренних настроек офиса. Названия Bubble Wrap/Webcam/Tamagotchi — только aliases визуальных примеров, их оригинальные материалы не включены.
