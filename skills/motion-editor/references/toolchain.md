# Практический локальный путь

## Проверяй доступное, не устанавливай весь стек

Нужны ffmpeg/ffprobe, Node.js, существующие совместимые React/Remotion зависимости и браузер для рендера. Python helpers используют стандартную библиотеку. Python с Whisper, если он найден отдельно, не означает доступность Whisper в произвольном system Python.

Используй отдельный совместимый Remotion engine: путь передаётся через `--engine-root`. Прочитай его package.json и установленную версию. Не меняй чужие исходники и lockfiles для нового монтажа. `scaffold_scene.py` создаёт отдельный проект и использует существующие node_modules. В публичном репозитории есть минимальный `engine/package.json`; установка описана в корневом README. Если engine/browser отсутствуют, назови конкретный пробел, подготовь исходники и согласуй только недостающую установку; не маскируй это под успешно сделанный MP4.

## Контактные листы

Из корня репозитория, задав пути к своему файлу и новой выходной папке:

```bash
python3 skills/motion-editor/scripts/inspect_reference.py \
  --input reference.mp4 --output-dir artifacts/reference-scan --step 2
```

Для движения используй `--start`, `--duration`, `--fps`; точные флаги см. `--help`. Индекс связывает ячейку с временем источника. Не применяй drawtext, не проверив наличие фильтра: в ряде сборок FFmpeg его нет. Храни временные подписи в JSON/отчёте, а не угадывай их по визуальному номеру.

## Рабочая сцена

```bash
python3 skills/motion-editor/scripts/scaffold_scene.py \
  --project artifacts/motion-demo \
  --engine-root engine \
  --style clean-editorial --width 1080 --height 1920 --fps 30 --duration 6
```

Открой созданные scene.json и SceneKit.tsx. Первый задаёт параметры; стилевой renderer в styles/<id>/Scene.tsx редактируется для конкретного визуального действия. Общий SceneKit.tsx отвечает за размещение и маршрутизацию к renderer, не содержит три смешанных темы. В проекте есть entry.tsx и локальная команда render.sh. Запускай из папки проекта. Непустой output project не должен затираться повторным scaffold; для новой версии используй новый каталог.

Доступные варианты берутся из styles/registry.json, не из зашитого списка. `scaffold_scene.py --list-styles` показывает актуальные IDs и aliases. Начальные три модуля сохраняют прежние IDs: clean-editorial, paper-collage, retro-vhs. В scene.json есть title/subtitle, labels из трёх строк, accent, layout и normalized panel. При lower-panel внешняя область прозрачна; для сборки с человеком можно передать свой backgroundVideo из public/. Речь/объекты не придумываются из sample labels — замени синтетический пример по настоящему плану.

**Граница kit:** это материал для начала работы, не универсальный генератор качественного выпуска по одному JSON. Если смысл требует карты/конкретного интерфейса/сложного движения, создай соответствующий компонент, вместо того чтобы вставлять неподходящую готовую карточку.

## Воспроизводимость и текст

Каждый видимый параметр вычисляется из frame/fps. В Remotion используй useCurrentFrame, interpolate, spring; реальные CSS timers/transition без синхронизации не подходят. Случайность только с постоянным seed. После скачков по timeline состояние одинаковое. Подготавливай локальные ассеты до рендера; не полагайся на временные URL и загрузку шрифта в середине экспорта.

Проверь кириллицу, реальные метрики шрифта и переносы. Указание font-family не доказывает наличие шрифта. System fallback допустим для демонстрации с явной пометкой; replica требует нужного файла или согласованной замены. Размер текста и безопасные отступы масштабируются относительно кадра, а не копируются из 16:9 в 9:16.

## Форматы

MP4/H.264 — готовый просмотр без прозрачности. Для отдельного оверлея используй совместимый с целевой сборкой alpha export: например, PNG sequence или ProRes4444 с alpha. Не обещай альфу в обычном H.264 MP4. Для Remotion проверенный пример flags: `--image-format=png --pixel-format=yuva444p10le --codec=prores --prores-profile=4444`. Проверь поддерживаемые flags установленной версии и результат ffprobe.

Если reference fractional/VFR — изучи timestamps. Приведение к30fps меняет кадры; при replica это осознанная адаптация, а не незаметное исправление.

## Альтернативы и расходы

HyperFrames подходит для HTML/GSAP-сцен и управляемого по времени рендера. Наличие local engine или core skills не означает доступность Pro и media-generation. `/reverse-any-video` документирован как Pro workflow; не запускай подписку, re-shoot человека или cloud upload как скрытый шаг. Собственная реконструкция локальными средствами возможна, но не наследует обещаний автоматического совпадения.

Manim полезен для объясняющих схем/формул; Blender — когда нужна реальная пространственная сцена/новый ракурс. Они не обязательны для бумажных вырезок, диска, карты и типографики. Кинематографичность плоской композиции часто создают именованные группы, параллакс и движение масштаба.

Для звука сначала имеющиеся разрешённые assets. Если нужен отсутствующий генератор/SaaS, укажи пользу, расходы и передачу данных; действуй в уже выданном объёме разрешения, без повторных согласований разрешённых операций.

Источники API/форматов: [Remotion animation](https://www.remotion.dev/docs/animating-properties), [alpha](https://www.remotion.dev/docs/transparent-videos), [HyperFrames](https://github.com/heygen-com/hyperframes). Проверять заново при смене установленной версии; не обновлять рабочий engine автоматически.

## Совместимость модульной версии

Сохранены имя motion-editor, прежние style IDs и флаги scaffold/inspect/check_plan, shape scene.json и signature SceneKit:React.FC<SceneConfig> в созданном проекте. Renderer-код каждого стиля находится в своей папке; project SceneKit.tsx генерируется из реестра. Старые самостоятельные проекты продолжают работать со своей сохранённой версией и не переписываются. Для получения нового каталога создай новый проект; правка registry не изменяет уже экспортированные проекты. В runtime всех зарегистрированных модулей есть исходники, но инструкции выбранного SKILL загружаются отдельно и лениво.
