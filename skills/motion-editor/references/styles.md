# Каталог стилей — совместимый вход

Визуальные правила вынесены в независимые модули. Источник доступного набора — [styles/registry.json](../styles/registry.json). Выбирай через `scripts/style_registry.py`, затем читай только SKILL.md выбранного стиля.

Начальные модули:

- [clean-editorial](../styles/clean-editorial/SKILL.md): референс Bubble Wrap, типографика и превращения предметов.
- [paper-collage](../styles/paper-collage/SKILL.md): референс Webcam, бумажные вырезки и движение группы.
- [retro-vhs](../styles/retro-vhs/SKILL.md): референс Tamagotchi, рекламная графика и независимый пиксельный экран.

Это три отдельных языка, не набор обязательных эффектов одного стиля. Новый модуль регистрируется по [контракту расширения](style-extension.md). Старый путь references/styles.md сохранён как указатель для совместимости; канонические инструкции находятся в стилевых SKILL.md.
