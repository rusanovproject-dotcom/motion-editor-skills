# Визуальная режиссура: минимум с наибольшей отдачей

## Фраза → предмет → действие

Выбирай визуал по мысли: процесс — передача/сборка предмета, сравнение — два состояния одного предмета, масштаб — размножение/камера, устройство — корпус и независимый экран, продукт — настоящая запись интерфейса. Конкретный продукт показывай его скриншотом/записью, а не выдуманным UI. Диаграмма требует исходных данных. Палитра и характер материала берутся только из выбранного стиля.

До кода запиши короткую партитуру: **подготовка → смысловое действие на anchor → читаемая остановка → выход/передача следующей сцене**. Длительности следуют речи и сложности чтения, не универсальным миллисекундам. Выдели одно главное движение; сдвиги появления поддерживают причинность. Если между сценами сохраняется предмет, продолжи его позицию/форму или проедь камерой группы вместо очередного одинакового fade. Не двигай камеру, текст и фон с одинаковой силой одновременно. Overshoot/spring подходит упругому предмету; строгой схеме может подходить плавная кривая без отскока.

Ключевой кадр сначала проверяет композицию. Затем обязательно проверь движение и самый неудачный промежуточный кадр: контраст на wipe, обрезку тени/overshoot, читаемость текста во время zoom. Motion blur, grain и VHS — завершающая обработка по стилю, они не исправляют слабую геометрию. В маленькой панели упрости сцену и текст, а не сжимай подробный постер; важная мысль должна читаться в масштабе финального телефона.

## Где взять материал и как встроить

Ищи конкретную недостающую вещь, например «вырезка камеры сбоку с прозрачным фоном», а не «крутые анимации». Сначала материалы пользователя и выбранного модуля. Дальше выбери один подход:

| Нужно | Подход | Как использовать |
|---|---|---|
| Схема, маршрут, обводка, предмет с меняющимся состоянием | Собственный SVG/React; [Remotion paths](https://www.remotion.dev/docs/paths) при уже доступном пакете | Отдельные управляемые слои; stroke-dashoffset/маска/transform вычисляются из кадра. Для простой линии дополнительный пакет не нужен |
| Предметный коллаж, продукт, фактура | Локальные PNG/WebP-вырезки, SVG, разрешённые фото/записи; при необходимости доступный image tool | Подготовь прозрачность и реальное разрешение, разнеси корпус/экран/тени. Статичная картинка — материал сцены, не вся анимация |
| Готовый маленький цикл/индикатор/иконка | [LottieFiles через официальную памятку Remotion](https://www.remotion.dev/docs/lottie/lottiefiles) | Выбери конкретный asset и условия использования, сохрани локальный JSON; [Lottie](https://www.remotion.dev/docs/lottie) требует соответствующего пакета и lottie-web. Проверь их наличие/версию, seek, цвета, loop и вход/выход. Наличие Remotion не означает, что Lottie установлен |
| Типографический/шейдерный приём или начало композиции | [Remotion templates](https://www.remotion.dev/templates/), [React Bits](https://github.com/DavidHDev/react-bits) как образцы | Выбери один приём, проверь условия исходника и зависимости. Браузерные hover/scroll, CSS timers, requestAnimationFrame нужно заменить кадрозависимым временем; веб-компонент не считается готовым видеоэффектом |

Новая зависимость или внешний генератор не обязательны ради декоративного эффекта. Если готовый asset несовместим/недоступен, сделай простую редактируемую версию средствами текущего проекта и назови замену. Не подменяй предмет универсальной карточкой только потому, что она уже есть в kit.

Для каждого взятого материала запиши в project asset manifest: `id`, локальный путь, source URL/владельца, условия/атрибуцию, exact/approximation/missing, роль и необходимые изменения. Привяжи его ID к assets сцены в существующем плане, не меняя формат этого плана. Приведи масштаб, свет, тени, цвет и фактуру к выбранному стилю; не смешивай несколько готовых пакетов без общего языка. Во время экспорта все необходимые файлы и шрифты уже локальны. Для неизвестных условий не объявляй asset разрешённым.

## Короткий проход качества

Проверь один характерный отрывок: смысл считывается без пояснения автора; основной текст успевает прочитаться; движение подчёркивает anchor; нет скачка предмета между сценами; выбранный материал выглядит частью стиля. Для talking-video добавь просмотр исходника до/во время/после вставки, лица, субтитров и звука. Исправляй сначала смысл, компоновку и тайминг, затем украшения. Это рекомендации режиссуры, а не обещание автоматического «1 в 1».
