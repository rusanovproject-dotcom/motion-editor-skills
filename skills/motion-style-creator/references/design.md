# Из референса или задачи в визуальный язык

Не начинай с выбора библиотеки. Сначала определи, какую мысль зритель должен увидеть: предмет раскрывается, система собирается, связи проявляются, число меняется, ошибка исправляется. Стиль задаёт способ показать это действие.

| Вход | Что извлекаем | Что не знаем |
|---|---|---|
| Видео | слои, материалы, иерархия, траектории, очередность/удержания по кадрам | оригинальные исходники, неизвестные шрифты, easing без плотного sampling |
| Картинка | форма, контраст, масштаб, композиция | хореография и звук; проектируем сами |
| Описание | задачу, настроение, ограничения, аудиторию | конкретный визуальный ответ; выбираем и помечаем авторским |

Паспорт держи коротким:

1. **Зачем**: объяснение, демонстрация механизма, сравнение, эмоциональная перебивка. Что должно оставаться читаемым на телефоне.
2. **Вид**: 2–4 цвета с ролями, один сильный предметный язык, основной/вспомогательный шрифт с доступностью, порядок слоёв и негативное пространство.
3. **Движение**: вход → действие, несущее смысл → читаемое удержание → выход. Для каждого жеста задай мотив, последовательность и зависимость от fps/длительности. Выбери характер — инерционный, механический, stop-motion и т. п. — вместо случайного spring для каждого объекта.
4. **Переносимость**: три рецепта «объект → действие → результат» на разных темах. Одинаковая декоративная заставка с новой подписью не считается новым рецептом.
5. **Два формата**: fullscreen даёт пространство для раскрытия, compact оставляет один доминирующий объект и меньше текста. Слишком сложную сцену разбей на два акта; не сжимай всё.
6. **Assets**: что рисуем SVG/кодом, что берём из локальных разрешённых assets, чему нужен внешний источник. У готовых snippets проверяй лицензию, возможность frame-driven rendering и реальную установленную зависимость. DOM/CSS анимации по реальному времени адаптируй к кадрам; не вставляй напрямую.

Не создавай ложную точность. Сохраняй unknown/approximation для отсутствующих текстур, cutouts, шрифтов. Эталон не разрешает скачивать чужие платные материалы. Не изображай точную копию при адаптации под другую палитру или формат.

При конфликте «ровно как X» и «совершенно другая типографика бренда» используй уже заданный приоритет; если его нет, уточни только этот выбор. Если автор просит просто красивый новый стиль, достаточно осмысленного авторского решения, без интервью о каждом параметре.
